    - buildCanonicalUrl('/', 'https://animalsvidadigna.org') -> 'https://animalsvidadigna.org/'
    - buildHreflangLinks(canonicalUrl, alternateUrl, locale) returns array of {hreflang, href} objects including self-reference, alternate, and x-default
    - buildHreflangLinks for CA locale: x-default points to canonicalUrl (CA is default)
    - buildHreflangLinks for ES locale: x-default points to alternateUrl (CA page)
    - buildOgMeta({title, description, url, locale, alternateLocale, image?, siteName?}) returns record of og property->content pairs
    - buildOgMeta always includes og:title, og:description, og:url, og:type, og:locale, og:locale:alternate, og:site_name
    - buildOrganizationSchema({name, url, logo, email}) returns valid JSON-LD Organization object with @context and @type
    - buildCatSchema({name, description, image, url, inLanguage}) returns valid JSON-LD Thing object with @context, @type, and all fields
    - buildCatSchema inLanguage is BCP 47: 'ca' or 'es'
  </behavior>
  <action>
    Create `src/lib/seo.ts` with these pure functions:

    1. `buildCanonicalUrl(pathname: string, site: string): string` -- joins site + pathname into absolute URL using `new URL(pathname, site).href`

    2. `buildHreflangLinks(canonicalUrl: string, alternateUrl: string, locale: 'ca' | 'es'): Array<{hreflang: string, href: string}>` -- returns 3 entries:
       - `{hreflang: locale, href: canonicalUrl}` (self-reference)
       - `{hreflang: locale === 'ca' ? 'es' : 'ca', href: alternateUrl}` (alternate)
       - `{hreflang: 'x-default', href: locale === 'ca' ? canonicalUrl : alternateUrl}` (default = CA)

    3. `buildOgMeta(opts: {title: string, description: string, url: string, locale: 'ca'|'es', image?: string, siteName?: string}): Record<string, string>` -- returns object with keys: `og:title`, `og:description`, `og:url`, `og:type` ('website'), `og:locale` (locale value), `og:locale:alternate` (other locale), `og:site_name` (defaults to 'Animals Vida Digna'). Conditionally includes `og:image` if provided.

    4. `buildOrganizationSchema(opts: {name: string, url: string, logo: string, email?: string}): object` -- returns `{"@context": "https://schema.org", "@type": "Organization", "name", "url", "logo", "contactPoint": {"@type": "ContactPoint", "email"}}`. Omit contactPoint if no email.

    5. `buildCatSchema(opts: {name: string, description: string, image: string, url: string, inLanguage: string}): object` -- returns `{"@context": "https://schema.org", "@type": "Thing", "name", "description", "image", "url", "inLanguage"}`.
