**Fix 3: CatGallery.astro — lazy-load Tobii with dynamic import**

In `src/components/cats/CatGallery.astro`, replace the entire `<script>` block (lines 42-58) with:

```html
<script>
  async function initLightbox() {
    const lightboxLinks = document.querySelectorAll('.lightbox');
    if (lightboxLinks.length > 0) {
      const [{ default: Tobii }, _css] = await Promise.all([
        import('@midzer/tobii'),
        import('@midzer/tobii/dist/tobii.min.css'),
      ]);
      new Tobii({ captions: true, zoom: false });
    }
  }

  // Initialize on first load
  initLightbox();

  // Also handle Astro SPA page-load events
  document.addEventListener('astro:page-load', () => {
    initLightbox();
  });
</script>
```

This changes from eagerly importing Tobii at module parse time to dynamically importing it only when lightbox links exist on the page. The CSS is also dynamically imported.

**Fix 5: BaseLayout.astro — change DonateSticky to client:idle**

In `src/layouts/BaseLayout.astro`, line 77, change `client:only="preact"` to `client:idle`:

From:
```html
<DonateSticky client:only="preact" url={donateUrl} text={t(locale, 'cta.donate')} />
```

To:
```html
<DonateSticky client:idle url={donateUrl} text={t(locale, 'cta.donate')} />
```

The DonateSticky only appears after 600px scroll. Using `client:idle` defers Preact hydration until the browser is idle, reducing TBT (Total Blocking Time) during initial load. Note: `client:idle` still SSRs the component (unlike `client:only`), so we need to ensure DonateSticky handles server rendering. Since the component returns `null` when `!visible` and `visible` starts as `false`, the SSR output will be empty, which is correct behavior (the component only shows after scroll anyway).
