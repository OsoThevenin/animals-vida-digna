These font names are referenced in Tailwind classes (font-sans, font-display) throughout
components but NO font files exist in /public/fonts/ and NO <link> tags load them.

attempts that slow rendering.

  <action>
    In `src/styles/global.css`, update the font family variables in the `@theme` block:

    Before:
    ```css
    --font-family-sans: "Inter", system-ui, sans-serif;
    --font-family-display: "Poppins", system-ui, sans-serif;
    ```

    After:
    ```css
    --font-family-sans: system-ui, -apple-system, "Segoe UI", Roboto, sans-serif;
    --font-family-display: system-ui, -apple-system, "Segoe UI", Roboto, sans-serif;
    ```

    Keep both variables (sans and display) so all existing `font-display` and `font-sans` Tailwind class usages continue to work. Both point to the same system font stack since we are not loading custom fonts.

    This eliminates any possibility of FOUT (Flash of Unstyled Text) and removes unnecessary font-matching network requests.
