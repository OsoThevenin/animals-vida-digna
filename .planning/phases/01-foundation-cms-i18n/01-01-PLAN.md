   ```
   pnpm add astro@5 @astrojs/cloudflare@12 @keystatic/core @keystatic/astro @astrojs/react @astrojs/markdoc react react-dom tailwindcss @tailwindcss/vite preact @astrojs/preact typescript
   pnpm add -D wrangler vitest @biomejs/biome
   ```

2. Create `astro.config.mjs` following the research Pattern 1:
   - Import cloudflare adapter, tailwindcss vite plugin, preact integration
   - Conditionally load Keystatic + React + Markdoc only when `process.env.NODE_ENV !== 'production'`
   - Set `adapter: cloudflare()` (no `output` field -- Astro 5 default is static with adapter)
   - Set `site: 'https://animalsvidadigna.org'`
   - Configure i18n: `defaultLocale: 'ca'`, `locales: ['ca', 'es']`, `routing: { prefixDefaultLocale: false }`
   - Add `@tailwindcss/vite` to `vite.plugins`
   - Do NOT enable Preact `compat` mode

3. Create `wrangler.toml`:
   ```toml
   name = "animals-vida-digna"
   compatibility_date = "2025-08-15"
   compatibility_flags = ["nodejs_compat"]

   [[r2_buckets]]
   binding = "IMAGES_BUCKET"
   bucket_name = "animals-vida-digna-images"
   ```

4. Create `tsconfig.json` extending Astro's strict config.

5. Create `src/styles/global.css` with Tailwind v4 CSS-first theme:

     - primary: warm brown (~#8B5E3C range)
     - accent: warm peach/orange (~#E8A87C range)
     - surface: warm off-white (~#FFF8F0)
     - text: dark brown (~#2D1B0E)
   - Add font-family tokens (Inter for body, Poppins for display -- or system-ui fallbacks)
   - Add border-radius tokens

   - `"preview": "astro preview"`
   - `"astro": "astro"`
