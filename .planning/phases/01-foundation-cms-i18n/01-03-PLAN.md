   - Export `type Locale = 'ca' | 'es'`
   - Export `locales`, `defaultLocale` constants

   - Export `getLocaleFromUrl(url: URL): Locale` -- checks if pathname starts with `/es`
   - Export `getAlternateUrl(url: URL, targetLocale: Locale): string` -- converts between CA (root) and ES (/es/) paths. Handle edge cases: root `/` to `/es`, `/es` to `/`, deep paths like `/cats/misi` to `/es/cats/misi`
   - All exports fully typed

2. Create `src/i18n/ca.ts` -- Catalan UI strings dictionary:
   - Navigation: 'nav.home', 'nav.cats', 'nav.about', 'nav.collaborate', 'nav.colonies', 'nav.contact'
   - CTAs: 'cta.adopt', 'cta.donate', 'cta.contact'
   - Common: 'common.language', 'common.switchLanguage'
   - Cat fields: 'cat.age', 'cat.gender', 'cat.male', 'cat.female', 'cat.status', etc.
   - Use Catalan labels from existing nav structure: "Qui som?", "Adopta'm", "Col·labora", "Apadrina'm", "Colonies felines"
   - Export as `default` typed object

3. Create `src/i18n/es.ts` -- Spanish UI strings dictionary:
   - Same keys as ca.ts, Spanish translations
   - Export as `default` typed object

4. Create `src/i18n/content.ts` -- Locale-aware content field reader:
   - Export `getLocalizedField<T>(entry: Record<string, T>, fieldName: string, locale: Locale): T` -- reads `entry[fieldName + '_' + locale]`
   - Export `getLocalizedCat(catEntry: any, locale: Locale)` -- returns a clean localized cat object with name, description, shortDescription, slug, coverImage alt, etc. mapped to the right locale. Shared fields (age, gender, status, etc.) passed through directly.
   - Import reader from `src/lib/keystatic.ts`

5. Create `tests/i18n.test.ts` covering I18N-01 through I18N-05:
   - **I18N-01**: `getLocaleFromUrl(new URL('https://x.com/'))` returns 'ca', `getLocaleFromUrl(new URL('https://x.com/cats'))` returns 'ca'
   - **I18N-02**: `getLocaleFromUrl(new URL('https://x.com/es'))` returns 'es', `getLocaleFromUrl(new URL('https://x.com/es/cats'))` returns 'es'
   - **I18N-03**: `getAlternateUrl` correctly maps '/' to '/es', '/es' to '/', '/cats/misi' to '/es/cats/misi', '/es/cats/misi' to '/cats/misi'
   - **I18N-04**: `t('ca', 'nav.home')` returns Catalan string, `t('es', 'nav.home')` returns Spanish string, both are non-empty and different
   - **I18N-05**: Verify no redirect middleware exists -- check that no `src/middleware.ts` file exists or if it does, it does not contain locale redirect logic
   - **Content helpers**: `getLocalizedField` correctly reads `_ca` and `_es` suffixed fields
