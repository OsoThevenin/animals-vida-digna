Create all landing section components as Astro components. Each receives its block `data` (the `value` from the block), `locale` ('ca' | 'es'), and optionally `donateUrl` or other props.

**Pattern for all components:** Use `getLocalizedField(data, fieldName, locale)` for text fields. For markdoc fields, use `renderMarkdoc()` from `src/lib/markdoc.ts` -- call it in the frontmatter section, pass the result via `set:html`. Always null-check data properties.

**HeroSection.astro** (LAND-02):
- Props: `{ data, locale, donateUrl }`
- Full-width section with large title, subtitle, hero image (from data.image), two CTA buttons (adopt links to /#gats or /es/#gatos, donate links to donateUrl)
- Use Tailwind: py-20, text-center or split layout, bg-surface
- CTA button text from data.ctaAdoptText_ca/es and data.ctaDonateText_ca/es via getLocalizedField

**AboutSection.astro** (LAND-03):
- Props: `{ data, locale }`
- Two-column layout (text + image on larger screens, stacked on mobile)
- Title from getLocalizedField(data, 'title', locale)
- Content rendered via renderMarkdoc -- call `renderMarkdoc(data[`content_${locale}`])` in frontmatter. NOTE: markdoc fields from blocks may already be resolved objects with `.node`, not async functions. If the field has a `.node` property directly, pass it to Markdoc.transform directly. Add a helper overload or check in renderMarkdoc to handle both cases.
- Image from data.image with localized alt

**StatsSection.astro** (LAND-04):
- Props: `{ data, locale }`
- Title + grid of stat items (3-4 columns). Each item shows value (large number) and label.
- Iterate data.items, use getLocalizedField on each item for label

**ColoniesSection.astro** (LAND-05):
- Props: `{ data, locale }`
- Similar to AboutSection -- title, markdoc content, optional image
- Use distinct section id for anchor linking (id="colonies" or id="colonias")

**AdoptSection.astro** (LAND-01 partial):
- Props: `{ data, locale }`
- Title + subtitle. This is a CTA section encouraging adoption. Link to the cats page.
- Include a "See all cats" type CTA linking to /cats or /es/cats

**CollaborateSection.astro** (LAND-06):
- Props: `{ data, locale }`
- Title, markdoc content, CTA button with text from data.ctaText_ca/es

**ContactCtaSection.astro** (LAND-07):
- Props: `{ data, locale }`
- Title, subtitle, CTA button (links to contact section or mailto). Form is Phase 3.

**FeaturedCatsSection.astro** (CATS-05):
- Props: `{ locale }`  (no data prop -- reads cats directly)
- In frontmatter: read all cats via `reader.collections.cats.all()`, filter by `featured === true`, map through `getLocalizedCat(entry, locale)`, sort by order
- Render a grid of CatCard components (3 columns on desktop, 1 on mobile)

**CatCard.astro** (shared component):
- Props: `{ cat: ReturnType<typeof getLocalizedCat> & { keystatic_slug: string }, locale: Locale }`
- Card with cover image (rounded top), name, short description, status badge
- Links to `/cat/${cat.slug}` or `/es/cat/${cat.slug}` based on locale
- Use Tailwind: rounded-xl, shadow-sm, hover:shadow-md, transition-shadow

**Landing pages (src/pages/index.astro and src/pages/es/index.astro)** (LAND-01):
- In frontmatter: read `landing` singleton and `settings` singleton via reader
- Determine locale ('ca' for index.astro, 'es' for es/index.astro)
- Get donateUrl from `settings?.donateUrl ?? '#'`
- Iterate `landing?.sections` array, use a switch on `section.discriminant` to render the correct component:
  - 'hero' -> HeroSection (pass donateUrl)
  - 'about' -> AboutSection
  - 'stats' -> StatsSection
  - 'colonies' -> ColoniesSection
  - 'adopt' -> AdoptSection
  - 'collaborate' -> CollaborateSection
  - 'contactCta' -> ContactCtaSection
  - For 'newsletter' and 'faq': render a placeholder div with a TODO comment (v2 features)
- After the sections loop, render FeaturedCatsSection
- Wrap in BaseLayout with proper title and description from settings SEO

**IMPORTANT anti-patterns to avoid:**
- Do NOT fetch settings inside each component -- read once in page, pass as props
- Do NOT pass markdoc ASTs to client-side islands -- render server-side only
- Null-check all CMS reads: `landing?.sections`, `settings?.donateUrl ?? '#'`
